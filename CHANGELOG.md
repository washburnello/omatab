# Changelog

Versions follow MAJOR.MINOR. Release scope is tracked in GitHub milestones; issues carry a `version:X.Y` label.

## 0.1 (unreleased)
- Named OmaTAB (Omarchy Time Awareness Bar); plugin id `washburnello.omatab`.
- Progress line drawn on the bar's own surface, in front of the strip, per screen.
- Hour / day / custom spans; custom start + length, loop or hold.
- Theme or preset colors, track opacity, 1–8 px thickness, inner or screen edge.
- Circle, triangle, diamond, tick, glow or no pip in three sizes.
- Bar icon: progress ring, tooltip with time left, right-click toggle, settings panel.
- Theme palette swatches, per-group reset buttons, default markers on sliders.
- Sparks: optional particle shower from the head during the loop sweep.
- Loop sweep: the marker eases back to zero when a span loops, with an optional rainbow.
- Works with the bar on any side; direction of travel (left/right, or up/down on a side bar).
